# MyVibe 🌟

> **Task & Habit Tracker** — Where every habit and task carries your own style.

MyVibe is a Flutter app that helps you manage tasks and habits in the most visual and personalized way. With dynamic card backgrounds, a rich background library, and a flexible tagging system, tracking your daily habits has never looked — or felt — this good.

---

## ✨ Key Features

### 🖼️ Dynamic Card Backgrounds
- Pick images from your local device (or upload) as the background for each task/habit card.
- Every card can carry its own "vibe" — family photos, landscapes, or anything that inspires you.

### 📚 Built-in Background Library
- Manage a ready-made background library right inside the app.
- Add new images to the library or reuse existing ones.
- Switch between backgrounds in just a few taps.

### 🏷️ Custom Tags
- Create your own tags with custom names and colors.
- Attach tags to any activity to categorize them: *work, health, study, personal...*
- Filter and group tasks/habits by tag quickly.

### 📌 Fixed Header, Always Visible
- The **date display**, **calendar picker button**, and **"Today" button** stay pinned at the top of the screen.
- They are not hidden when you switch to the **"Completed"** tab — you always know which day you're viewing and can jump back to today instantly.
